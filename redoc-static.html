AgroConnect API (1.0.0)

Download OpenAPI specification:

URL: https://github.com/Jmukami/farmers-agroconnect License: MIT

AgroConnect is a full-stack digital agricultural marketplace and service platform connecting Kenyan farmers, farm input/service suppliers, and buyers.

This OpenAPI specification defines the REST API contract for the AgroConnect platform, serving both internally and our downstream integration partners: Campus Hub / Team 7).
